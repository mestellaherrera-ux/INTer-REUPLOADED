# INTer-REUPLOADED
PS2 Texture Reupload de herramientas y especificaciones para modificar texturas .TM0 / TIM2 de la app interna de PaRappa the Rapper 2 (PS2). Este repositorio recopila los archivos necesarios para la extracción, conversión y reempaquetado de gráficos indexados (CLUT) sin errores de lectura en emuladores (PCSX2) o hardware real.
